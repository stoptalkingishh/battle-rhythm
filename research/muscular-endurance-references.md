# Muscular-Endurance Form References

Scope: the eight exercises classified as `muscular-endurance` in `js/data/exercises.js`. These are public references for studying movement form, not assets to copy. ATP 7-22.02 is the primary H2F drill-and-exercise visual authority. The current Army Fitness Test (AFT) has five events: HRP and plank are the relevant current test events; the leg tuck is historic and is **not an AFT event**.

## Push-Up

**H2F cue cross-check:** ATP Preparation Drill's push-up starts in front-leaning rest, keeps the body generally straight, and lowers until the upper arms are parallel to the ground. This agrees with the app's hand-under-shoulders, straight-line, roughly 45-degree-elbow cue; use the Army illustration as the controlling model when cues differ.

1. [U.S. Army, *ATP 7-22.02: Holistic Health and Fitness Drills and Exercises* (active publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020967). Visual model: Preparation Drill push-up figure establishes front-leaning-rest start and a rigid head-to-heel line.
2. [U.S. Army, *ATP 7-22.02* PDF, Preparation Drill](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: use the push-up's start, down, and return illustrations to show a single-unit torso rather than a hip hinge.
3. [U.S. Army, *FM 7-22: Army Physical Readiness Training* (historic)](https://irp.fas.org/doddir/army/fm7-22.pdf). Visual model: predecessor PRT illustrations provide the same drill cadence and range-of-motion sequence.
4. [American Council on Exercise, *Push-Up* exercise library](https://www.acefitness.org/resources/everyone/exercise-library/66/push-up/). Visual model: side-view progression is useful for checking neutral trunk and controlled elbow flexion; it is a general-training, not AFT, model.
5. [ExRx.net, *Bodyweight Push-Up*](https://exrx.net/WeightExercises/PectoralSternal/BWPushup). Visual model: animation separates start and bottom positions, making shoulder, elbow, and trunk alignment inspectable.

**Model baseline:** (1) create an original side-profile SVG with three keyed poses: front-leaning rest, upper arms parallel, and return; (2) show one straight head-to-heel alignment guide and a shoulder-to-wrist vertical guide; (3) use simple original line art, arrowed motion path, and descriptive text, not source photos, frames, or traced figures.

## Hand-Release Push-Up

**H2F cue cross-check:** the current AFT standard controls: chest, hips, and thighs touch down together; the hands release into a T; hands return before the next whole-body push. The app's "release hands" cue needs this full T-position and single-unit body detail.

1. [U.S. Army, *Army Fitness Test: Hand-Release Push-Up - Arm Extension*](https://www.army.mil/aft). Visual model: current official event card, illustration, and linked demonstration define the sequence and no-count body-position faults.
2. [U.S. Army, *AFT HRP demonstration video*](https://www.youtube.com/watch?v=9mO6ygDS7y4&list=PLr_5M5FiwX8gmAIq7IhRi8o5u2k9qn1qo&index=4). Visual model: watch the complete ground contact, lateral arm extension, hand reset, and one-unit press as separate phases.
3. [U.S. Army, *AFT HRP technique illustration*](https://www.army.mil/e2/images/rv7/aft/pushup/figure.svg). Visual model: official vector reference for prone setup and front-leaning-rest alignment.
4. [U.S. Army, *ATP 7-22.01: Holistic Health and Fitness Testing* (publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020966). Visual model: testing authority for event administration; cross-check the demonstration against current test rules.
5. [U.S. Army, *ATP 7-22.02: H2F Drills and Exercises* PDF](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: the Preparation Drill push-up is the non-test baseline for front-leaning-rest alignment and controlled press mechanics.

**Model baseline:** (1) create four original SVG frames: prone contact, locked-out front-leaning rest, T arm release, and hand reset; (2) annotate that chest/hips/thighs contact together and that the body stays as one unit; (3) include an explicit T-arm arrow and avoid presenting a generic push-up as the test movement.

## Plank

**H2F cue cross-check:** current AFT plank requires elbows under shoulders, forearms forming a triangle, feet/forearms/hands on the floor, and straight head-to-heel alignment. This refines the app cue from a generic forearm plank to the test-specific hand and forearm configuration.

1. [U.S. Army, *Army Fitness Test: Plank*](https://www.army.mil/aft). Visual model: current event card specifies the permitted contact points and termination conditions.
2. [U.S. Army, *AFT Plank demonstration video*](https://www.youtube.com/watch?v=XuprZeJa7G0&list=PLr_5M5FiwX8gmAIq7IhRi8o5u2k9qn1qo&index=6). Visual model: shows the test setup from knees to the held straight-line position.
3. [U.S. Army, *AFT plank technique illustration*](https://www.army.mil/e2/images/rv7/aft/plank/figure.svg). Visual model: official vector reference for the forearm triangle and line of the body.
4. [U.S. Army, *ATP 7-22.01: H2F Testing* (publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020966). Visual model: test authority to use with the AFT demonstration for setup and fault interpretation.
5. [Mayo Clinic, *Exercises to improve your core strength*](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/core-strength/art-20546851). Visual model: medically reviewed illustrated modified-plank progression reinforces shoulders-over-elbows and neutral head/neck; it is a training regression, not the AFT standard.

**Model baseline:** (1) create an original SVG showing the AFT forearm triangle, not clasped hands; (2) show side and top inset views with elbow-under-shoulder and head-to-heel guides; (3) mark permitted floor contacts and a separate sagged-hip no-count silhouette.

## V-Up

**H2F cue cross-check:** ATP Conditioning Drill 1 uses a controlled supine-to-V movement with straight legs and trunk rising together. This agrees with the app's V shape and controlled descent; do not substitute a bent-knee crunch.

1. [U.S. Army, *ATP 7-22.02* PDF, Conditioning Drill 1](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: the V-Up figure is the primary H2F sequence for the supine start, V position, and return.
2. [U.S. Army, *ATP 7-22.02* (active publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020967). Visual model: authoritative drill source and edition metadata for the illustrated CD1 V-Up.
3. [U.S. Army, *FM 7-22: Army Physical Readiness Training* (historic)](https://irp.fas.org/doddir/army/fm7-22.pdf). Visual model: predecessor CD1 visual confirms the straight-leg, simultaneous trunk-and-leg pattern.
4. [ExRx.net, *Bodyweight V-Up*](https://exrx.net/WeightExercises/RectusAbdominis/BWVUp). Visual model: animation provides a useful side-view check that the legs remain long rather than cycling.
5. [National Academy of Sports Medicine, *V-Up* exercise library](https://www.nasm.org/exercise-library/v-up). Visual model: general-training demonstration can be used to compare controlled start and finish positions, while ATP remains controlling.

**Model baseline:** (1) create original SVG start, peak, and return poses on a floor line; (2) depict straight knees and simultaneous trunk/leg arrows meeting in a clear V; (3) add a controlled-downward arrow and a no-momentum note without copying any source image.

## Mountain Climber

**H2F cue cross-check:** ATP Conditioning Drill 1 performs alternating knee drives from front-leaning rest while preserving trunk control. This supports the app's hips-level cue; the image should make alternating sides unambiguous rather than portray a running-in-place pose.

1. [U.S. Army, *ATP 7-22.02* PDF, Conditioning Drill 1](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: primary H2F mountain-climber poses establish the front-leaning-rest base and alternating knee drive.
2. [U.S. Army, *ATP 7-22.02* (active publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020967). Visual model: primary publication record for the controlling drill illustration.
3. [U.S. Army, *FM 7-22: Army Physical Readiness Training* (historic)](https://irp.fas.org/doddir/army/fm7-22.pdf). Visual model: historic PRT CD1 illustration gives the same alternating-position visual sequence.
4. [American Council on Exercise, *Mountain Climber* exercise library](https://www.acefitness.org/resources/everyone/exercise-library/). Visual model: use the library's movement demonstration to check shoulders over hands and alternating knee travel; it is a general-training comparison.
5. [ExRx.net, *Bodyweight Mountain Climber*](https://exrx.net/WeightExercises/HipFlexors/BWMountainClimber). Visual model: animation isolates the alternating hip-flexion action while retaining the supported upper body.

**Model baseline:** (1) create an original three-pose SVG: front-leaning rest, left-knee drive, right-knee drive; (2) retain fixed hand/shoulder placement and add a horizontal hip-level guide; (3) use alternating, color-independent arrow labels "L" and "R" with no borrowed video frames.

## Leg Tuck

**Historic/non-AFT status:** the leg tuck was an ACFT event, but it is **not an AFT event** as of the AFT's June 1, 2025 implementation. Treat it as a Climbing Drill 1 training movement, not a current test standard.

**H2F cue cross-check:** ATP Climbing Drill 1's form is a bar hang followed by knees traveling toward the elbows and a controlled return. This matches the app cue; do not model it as a free-hanging knee raise that stops short of elbow contact.

1. [U.S. Army, *ATP 7-22.02* PDF, Climbing Drill 1](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: primary H2F illustration for the hang, knee-to-elbow tuck, and controlled lower.
2. [U.S. Army, *ATP 7-22.02* (active publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020967). Visual model: current Army drill authority; confirms this exercise persists as training even though it is not an AFT event.
3. [U.S. Army, *Army Fitness Test*](https://www.army.mil/aft). Visual model: current official event list is the status cross-check: it has no leg-tuck event.
4. [U.S. Army, *FM 7-22: Army Physical Readiness Training* (historic)](https://irp.fas.org/doddir/army/fm7-22.pdf). Visual model: historic climbing-drill illustration provides a second Army visual for the knee-to-elbow endpoint.
5. [ExRx.net, *Bodyweight Hanging Knee Raise*](https://exrx.net/WeightExercises/RectusAbdominis/BWHangingKneeRaise). Visual model: general-training animation is a partial analogue for the controlled hanging return only; it does not replace the Army knee-to-elbow endpoint.

**Model baseline:** (1) label the asset "Historic ACFT / current CD1 training movement - not AFT"; (2) create original hang, knees-to-elbows, and controlled-lower SVG poses with a clearly drawn bar and closed grip; (3) show elbow contact as the endpoint and prohibit a generic partial knee-raise depiction.

## Rower

**H2F cue cross-check:** ATP Preparation Drill's rower starts supine with knees bent and feet together, curls/rocks to seated, then rocks back under control. This matches the app's cues and is not an ergometer rowing stroke.

1. [U.S. Army, *ATP 7-22.02* PDF, Preparation Drill](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: primary H2F rower figure establishes the supine, tucked, seated, and rock-back path.
2. [U.S. Army, *ATP 7-22.02* (active publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020967). Visual model: active controlling reference for this specifically named Army drill.
3. [U.S. Army, *FM 7-22: Army Physical Readiness Training* (historic)](https://irp.fas.org/doddir/army/fm7-22.pdf). Visual model: historic Preparation Drill depiction provides the same distinctive rocking sequence.
4. [U.S. Army, *Army Fitness Test*](https://www.army.mil/aft). Visual model: current H2F/AFT hub that links the active drills authority; it also prevents confusing the bodyweight rower with a test event or rowing machine.
5. [Mayo Clinic, *Exercises to improve your core strength*](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/core-strength/art-20546851). Visual model: illustrated supine core movements are a conservative posture cross-check for neutral, controlled trunk motion, not a substitute for the Army rower sequence.

**Model baseline:** (1) title the original SVG "Rower (Preparation Drill), not rowing ergometer"; (2) show four poses from supine to compact seated rock with feet together and bent knees; (3) draw a continuous curved rock path and require the return to be controlled, without a neck-pulling gesture.

## Bent-Leg Body Twist

**H2F cue cross-check:** ATP Preparation Drill uses a supine setup with hips and knees at approximately 90 degrees; legs rotate side-to-side while the upper back/shoulders remain grounded. This precisely matches the app cue and rules out a seated Russian twist.

1. [U.S. Army, *ATP 7-22.02* PDF, Preparation Drill](https://armypubs.army.mil/epubs/DR_pubs/DR_a/ARN45013-ATP_7-22.02-001-WEB-4.pdf). Visual model: primary H2F figure shows the 90-degree bent-leg starting geometry and side-to-side rotation.
2. [U.S. Army, *ATP 7-22.02* (active publication record)](https://armypubs.army.mil/ProductMaps/PubForm/Details.aspx?PUB_ID=1020967). Visual model: active publication record for the authoritative Preparation Drill illustration.
3. [U.S. Army, *FM 7-22: Army Physical Readiness Training* (historic)](https://irp.fas.org/doddir/army/fm7-22.pdf). Visual model: predecessor PRT image confirms the shoulders-down, bent-leg rotational pattern.
4. [Mayo Clinic, *Exercises to improve your core strength*](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/core-strength/art-20546851). Visual model: the illustrated double-leg 90-degree supine setup is a medical-source cross-check for the required starting geometry; it is not the full twist demonstration.
5. [Harvard Health Publishing, *The best core exercises for older adults*](https://www.health.harvard.edu/healthy-aging-and-longevity/the-best-core-exercises-for-older-adults). Visual model: clinician-reviewed core guidance reinforces slow, controlled trunk work; use only as a safety/form comparison, with ATP controlling the exact twist.

**Model baseline:** (1) create an original overhead-plus-side SVG with hips and knees visibly at 90 degrees; (2) show left and right leg-rotation endpoints with shoulders and upper back anchored to the floor; (3) label it "Bent-Leg Body Twist (Preparation Drill), not seated twist" and use bilateral arrows without tracing source art.
